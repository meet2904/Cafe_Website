# Beakk & Brew | Artisan Roastery & Pâtisserie

A responsive website for **Beakk and Brew**, featuring single-origin coffee, artisan viennoiserie, interactive menu tasting carte, custom sliding tasting tray drawer, and embedded Google Maps.

## 🚀 Live Preview & Deployment

This project is built with HTML5, Tailwind CSS, and Vite. It is optimized for zero-config deployment on [Vercel](https://vercel.com).

### Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run local server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

3. **Build for production:**
   ```bash
   npm run build
   ```

## 🛠️ Features

- **Responsive Design**: Mobile, tablet, and desktop layouts.
- **Micro-Interactions**: Gentle floating badges, card hover lift, and image zoom.
- **Dynamic Navigation**: Active indicator that follows clicks and page scroll with ScrollSpy.
- **Interactive Tasting Carte**: Filterable tabs for Espresso, Cold Brew, Artisan Teas, and Bakery.
- **Sliding Tasting Tray**: Slide-over drawer with item adjustment and cart feedback.
- **Location & Google Maps**: Embedded interactive map centered on Bhaktinagar Circle, Rajkot.
- **Table Reservation Form**: Interactive booking form with instant confirmation feedback.
